# The Auction Ledger

Product: a personal World of Warcraft Auction House observatory. Compare daily/twice-daily Auctioneer listing snapshots and Auctionator price history, discover price movers, inspect listed supply, track favorites, estimate resale proceeds after configurable fees. Static GitHub Pages, all imports parsed locally; no account identifiers published.

Character: seasoned, exact, adventurous. World: an auctioneer's brass-bound field ledger in a candlelit trading hall. Signature: compact gold/silver/copper denominations and square quality-colored item frames. Rich moments: real Warcraft landscape in a shallow masthead and an amber price-history chart.

Primary library reference: cinematic-style, adapted to a usable financial ledger. Keep cinematic depth and deliberate composition; user-facing usability and unslop guidance override the library's oversized headings, neon gradients, blur and motion. No neon, purple wash, gradients on text, glass cards, uppercase tracked labels, artificial live indicators, emoji, invented social proof, or enormous empty hero.

Palette: background #121310, sidebar #0d0f0d, panel #191b17, raised #22251f, border #34392c, text #eae6d9, secondary #a5ad9c, muted #929b89. Brass accent #d4b16a, positive #8ac49a, negative #e39482. Warcraft item rarity is meaningful blue/purple, not interface decoration.

Typography: Georgia serif for product and section headings, system sans for controls/body, system monospace/tabular figures for market prices. H1 40px normal, H2 22px normal, body 14px, small 12px. No decorative display fonts needed.

Layout: 216px quiet sidebar desktop, main max 1440px with 32px padding. Compact top bar, shallow illustrated masthead, demo notice, four inline stats, 2:1 chart and top-movers list, full-width searchable sortable item ledger below. Clear import action top right; realm/faction market selector and 24h/7d/30d segmented period. Mobile: horizontal nav, stacked chart/list, scrollable table. Spacing multiples of 4px. Radius 4px buttons/inputs, 8px panels. Borders rather than shadows. Motion limited to 150ms color changes; respect reduced motion.

Data semantics: prices in copper, unit buyouts, distinguish listings from units. Missing supply stays unknown. Price index uses a matched basket. Trends compare observed scans with explicit reference dates. Sample data clearly labeled. No claims of actual sales or guaranteed profit. Profit calculator exposes buy price, target sale price, quantity, AH cut and nonrefundable expenses. No hidden offsite dependencies for runtime charts or parsing.

Views: overview; item ledger; watchlist; scan library/import dialog; item detail with price-history chart and resale calculator. Native accessible dialogs, explicit labels, focus indicators, keyboard-operable controls, useful empty/error states. First screen should look like a crafted Warcraft trading tool, not an admin template.

Design reference: unslop by Damir Sokolovsky, https://x.com/heydamir, CC BY 4.0.
