# Asset and format sources

- Classic control artwork: original Blizzard textures from the [Classic branch of Gethe/wow-ui-textures](https://github.com/Gethe/wow-ui-textures/tree/classic). Red and stone buttons, pressed states, close controls, checkboxes and scrollbar arrows/knobs come from `Buttons/`. Active/inactive tabs come from `OPTIONSFRAME/UI-OptionsFrame-*Tab.PNG`; input borders from `COMMON/Common-Input-Border.PNG`; currency icons from `MONEYFRAME/`.
- Metal/gold frame borders and dark dialog tiles: `DialogFrame/UI-DialogBox-*`. `scripts/prepare-ui.mjs` embeds the original PNG pieces in SVG viewports to assemble CSS nine-slice frames; the border pieces follow Blizzard's [Backdrop texture layout](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_SharedXML/Backdrop.lua). Edges repeat, corners retain their proportions, and the original artwork is not repainted. The slider inset frame and tile use `Buttons/UI-SliderBar-*`. Rebuild these SVGs with `node scripts/prepare-ui.mjs` after changing the source textures.
- Dark mottled panel texture: copied read-only from the local game installation's `EnhanceQoL/Assets/background_dark.tga`, converted to PNG. No game files were changed.
- Full-page background: Blizzard's original `FrameGeneral/UI-Background-Rock.PNG`, from the [Classic UI texture mirror](https://github.com/Gethe/wow-ui-textures/blob/classic/FrameGeneral/UI-Background-Rock.PNG), tiled at its native 256×256 size without a dark overlay.
- Warcraft item icons: Blizzard Entertainment, retrieved through [Wowhead's icon CDN](https://wow.zamimg.com/images/wow/icons/large/inv_misc_coin_01.jpg). Included icons serve locally; unbundled icons use that CDN as a fallback.
- Item names, icon keys, categories and qualities: the public [nexus-devs/wow-classic-items dataset](https://github.com/nexus-devs/wow-classic-items/blob/master/data/json/data.json). Only metadata for items in this ledger is included, plus a small reference catalog. Custom/new items absent from it retain item IDs.
- Design guided by [unslop by Damir Sokolovsky](https://x.com/heydamir), CC BY 4.0, and a Superdesign draft. No external UI framework, fonts, charting scripts or parser dependencies run in the site.
- Auctionator field semantics checked against public [Database/Mixin.lua](https://github.com/JedborgWoW/Auctionator-3.3.5a/blob/main/Source/Database/Mixin.lua) and [Constants/Main.lua](https://github.com/JedborgWoW/Auctionator-3.3.5a/blob/main/Source/Constants/Main.lua). CBOR reader independently implements the relevant subset of [RFC 8949](https://www.rfc-editor.org/rfc/rfc8949).
- Auctioneer fields checked against [CoreConst.lua](https://github.com/ckrebs95/WoW/blob/master/interface/AddOns/Auc-Advanced/CoreConst.lua) and the installed v1.4 ScanData container, read only. Decoder accepts literal tables and `return {…}` ropes, never executes Lua.
